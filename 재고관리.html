확장이 못 가는 곳이나, 새 상품 주소를 학습시킬 때 쓴다. 아래 두 개를 북마크바로 끌어다 놓는다 (안 보이면 Ctrl+Shift+B).

새 상품을 넣을 때

  1. 상품 폴더와 이미지를 넣고 npm run catalog:import
  2. 이 페이지를 npm run manage 로 다시 만든다 → 새 상품이 맨 위에 주소 없음으로 뜬다
  3. 공식몰 상품 페이지 주소를 칸에 붙여 넣고, 위 JSON 을 official-urls.json 에 저장
  4. npm run catalog:import 다시 → npm run extension → 크롬에서 확장 새로고침

캐나다구스처럼 색상마다 페이지가 다른 브랜드는 색상별 칸을 쓴다. 경로가 같은 주소는 자동으로 하나로 접히므로 같은 페이지를 여러 번 열지 않는다.
