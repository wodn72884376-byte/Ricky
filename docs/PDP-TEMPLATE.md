# 상품 상세페이지(PDP) 템플릿

> 출처: 세레나마켓 스마트스토어 상세페이지 (2026-08-26 첨부)
> 시각 시스템: [DESIGN.md](../DESIGN.md) — 29cm 기반 RICKY 디자인 시스템
> 관련: [PROJECT.md](../PROJECT.md) §3 비즈니스 규칙

---

## 0. 이 문서가 하는 일

첨부된 세레나마켓 상세페이지에서 **정보 구조(무엇을 어떤 순서로 말하는가)** 를 가져오고,
**시각 표현(어떻게 보이는가)** 은 RICKY 디자인 시스템으로 대체한다.

두 레퍼런스는 정반대 레지스터다. 세레나마켓은 스마트스토어 관용 — 이모지, 형광 하이라이트,
별 장식, 핑크 박스, 느낌표. RICKY가 채택한 29cm 계열은 그 전부를 금지한다. 그럼에도 세레나마켓의
**신뢰 구축 순서**는 크로스보더 커머스에서 검증된 구조이며, 그대로 가져올 가치가 있다:

> 사회적 증명 → 정품 약속 → 취급 브랜드 → 차별점 → 실제 후기 → 구매 전 고지 → 이벤트

이 순서를 유지하되, 각 섹션을 RICKY의 토큰과 목소리로 다시 조판한다.

## 1. 레지스터 변환표

| 세레나마켓 | RICKY | 근거 |
|---|---|---|
| ⭐🍁💗 이모지 장식 | 제거 | DESIGN.md §10 — 마케팅 surface 이모지 금지 |
| 형광 노랑/핑크 하이라이트 텍스트 | weight 700 흑색 | §3 — 강조는 웨이트로만 |
| 핑크 라운드 박스 (`구매 전 체크 사항`) | 흰 배경 + 여백 분리, 보더 없음 | §6 — 지면은 평평 |
| `100% 정품 약속!!!` | `모든 상품은 캐나다 공식 매장에서 매입해요` | §10 — 정품은 느낌표가 아니라 문서로 증명 |
| 별점 이미지 ★★★★★ | 숫자 + 텍스트, 또는 생략 | §4 — 장식 아이콘 없음 |
| 원색 배지 (`EVENT`, `100%`) | 반전 블랙 칩 또는 텍스트 | §2 — 브랜드 컬러는 흑백 |
| 느낌표 종결 (`더욱 빠르게!`) | 평서 종결 (`더 빠르게 도착해요`) | §10 — 들뜨지 않는 목소리 |
| 배너 이미지에 텍스트 굽기 | 실제 텍스트로 조판 | 접근성·검색·번역·유지보수 |
| `구매대행` | `직접 매입해 판매` | §10 금지어 — 소매상 지위 (PROJECT.md §3.1) |

**배너에 텍스트를 굽지 않는다**는 항목은 특히 중요하다. 세레나마켓 페이지는 거의 전부가 이미지다.
RICKY는 상품마다 가격·재고·세액이 달라지므로, 텍스트를 이미지로 만들면 상품 하나 바뀔 때마다
디자이너가 필요해진다. 사진만 이미지고 나머지는 전부 조판이다.

## 2. 섹션 구조

### §1 히어로 — 상품 사진 + 최소 정보

- 풀블리드 상품 사진 (4:5 또는 1:1, 0px 반경)
- 브랜드명: 24px/700 라틴 (`Arc'teryx`)
- 상품명: 22px/700 한국어
- 가격: 12px/700 → **상세페이지에서는 22px/700까지 허용** (카드가 아니라 상세이므로)
- 가격 아래 캡션 12px/400 muted: `관세·부가세 별도` + 예상 세액
- 구매 CTA: 반전 블랙 52px, 화면당 하나
- 재고 상태: §14 상태 규칙 그대로 (`재고를 확인하고 있어요` / `지금은 재입고를 기다리는 중이에요`)

> 세레나마켓은 히어로에 `10만 이상 고객님들께서 선택 해주신` 같은 사회적 증명을 먼저 둔다.
> RICKY는 상품을 먼저 둔다 — 사진이 헤드라인이다(DESIGN.md §12-1). 사회적 증명은 §5로 내린다.

### §2 정품 약속 — 4개 사실

세레나마켓의 4불릿을 사실 진술로 바꾼 것. 22px/700 섹션 제목 + 15px/400 본문 4행.

| 항목 | 카피 |
|---|---|
| 매입처 | `모든 상품은 캐나다 공식 매장에서 직접 매입해요.` |
| 배송 | `주 3회 출고해요. 캘거리 출고 후 영업일 기준 7~14일 걸려요.` |
| 상담 | `한국 시간 기준으로 응대해요. 시차를 기다릴 필요 없어요.` |
| 교환·반품 | `해외 배송이어도 교환과 반품이 가능해요.` |

느낌표 없음. `OK!` 없음. 각 행은 검증 가능한 사실이어야 하며, 지킬 수 없는 항목은 삭제한다.

### §3 취급 브랜드

- 라틴 브랜드명 24-30px/700 가로 나열: `Arc'teryx` · `lululemon` · `Coach`
- 브랜드별 대표 상품 사진 그리드 (0px 반경, 그림자 없음)
- 브랜드 로고를 쓰지 않는다 — 상표 사용 리스크. 텍스트 워드마크로 표기한다.

### §4 차별점 — 온라인 쇼핑의 한계

세레나마켓의 3불릿을 그대로 승계한다. 이 셋이 크로스보더에서 실제로 작동하는 차별점이다.

| 항목 | 카피 | 시각 |
|---|---|---|
| 검수 사진 | `출고 전에 실물 택과 시리얼을 촬영해서 남겨요.` | 검수 사진 카드 그리드 (DESIGN.md §4) |
| 포장 | `박스 포장 후 항공 특송으로 보내요.` | 포장 사진 |
| 증빙 | `매입 영수증과 인보이스를 함께 넣어요.` | 영수증 사진 (금액·개인정보 마스킹) |

**검수 사진은 이 페이지의 핵심 자산이다.** 보정·워터마크·`정품 100%` 스탬프를 얹지 않는다.
얹는 순간 증거가 광고가 된다.

### §5 실제 후기

- 후기 3건, 각각 15px/400 본문 + 12px/400 muted 작성일
- 별점은 이미지가 아니라 `5.0` 숫자 또는 생략
- 우측에 해당 주문의 검수 사진 1장
- 후기는 실제 구매 확인된 것만. 없으면 **이 섹션을 통째로 비운다** — 채우지 않는다

### §6 구매 전 고지

세레나마켓의 핑크 박스를 흰 지면 + 여백으로 재조판. 13-15px/400, 항목 사이 16px.

**(1) 고객센터**
```
평일 오전 10시 ~ 오후 3시 (주말·공휴일 제외)
[FILL IN: 상담 채널 — 네이버 톡톡 / 카카오채널 / 자사 문의폼]
```

**(2) 개인통관고유부호 — 검증 강화 안내**
```
세관 통관 시 개인통관고유부호 검증이 강화되었어요.
수령인의 성명 · 연락처 · 통관부호 · 주소가 모두 일치해야 하며,
하나라도 다르면 통관이 지연될 수 있어요.
```
> 이 문구는 체크아웃 PCCC 입력 필드 옆에도 동일하게 노출한다.

**(3) 관세·부가세 (DDU)**
```
미화 150달러 이하는 관세와 부가세가 면제돼요.
넘으면 상품가와 국제 운임을 합한 금액 전체에 관세와 부가세 10%가 부과되고,
통관할 때 수취인이 납부해요. 이 상품의 예상 세액은 약 OO원이에요.
```
빨간색·경고 아이콘·틴트 배경 금지 (DESIGN.md §12-9).

**(4) 판매자 지위 고지 — 문안 주의**

세레나마켓 원문은 다음과 같다:
> "세레나마켓은 고객님을 대신하여 상품을 구매·배송해드리는 **구매대행 업체**로,
> 브랜드의 공식 수입사·총판 또는 대리점이 아니며, 해당 브랜드와는 직접적인 관계가 없는
> 독립적인 사업자입니다."

**이 문장을 그대로 쓰면 안 된다.** 앞 절(`고객을 대신하여 구매하는 구매대행 업체`)이
RICKY의 소매상(Principal) 지위를 스스로 부정한다. 뒷 절(공식 수입사·총판·대리점 아님)은
상표·소비자 오인 방지를 위해 **반드시 유지해야 한다.**

RICKY 문안:
```
RICKY는 캐나다 현지 공식 매장에서 상품을 직접 매입해 판매하는 독립 사업자예요.
각 브랜드의 공식 수입사·총판·대리점이 아니며, 브랜드와 직접적인 제휴 관계는 없어요.
국제 배송 중 발생한 파손·분실에 대한 1차 책임은 RICKY가 집니다.
```
마지막 문장은 소매상 지위의 근거이므로 이용약관과 함께 반드시 노출한다(PROJECT.md §3.6).

**(5) 사이즈 안내**
```
사이즈는 브랜드가 제공하는 가이드를 따라요.
확인이 필요하면 상품 Q&A로 문의해 주세요.
```

### §7 이벤트 (선택)

세레나마켓은 포토리뷰 추첨 → 네이버 포인트 1만원. 자사몰에는 네이버 포인트가 없으므로
적립금·쿠폰 등 자체 수단이 필요하다. **P5 이후 과제로 미룬다.**
노출 시에도 카운트다운·`마감 임박`은 쓰지 않는다(DESIGN.md §10).

| 검수 사진 | `inspection_photos` (`is_public = true`인 것만 스토어 노출) |

### 스키마 보강 — 적용 완료 (2026-08-26)

아래는 `supabase/migrations/20260826000003_guest_orders_and_support.sql`로 적용됐다.
실제 정의는 마이그레이션이 원본이며, 여기 남긴 것은 설계 의도의 기록이다:

```sql
-- 출고 전 검수 기록 (상품이 아니라 주문/출고 단위)
create table inspection_photos (
  id          uuid primary key default gen_random_uuid(),
  order_id    uuid references orders(id) on delete cascade,
  variant_id  uuid references product_variants(id) on delete set null,
  kind        text not null,        -- 'tag' | 'serial' | 'size_label' | 'stitching' | 'packaging' | 'receipt'
  storage_path text not null,       -- Supabase Storage
  caption     text,
  shot_at     timestamptz not null default now(),
  -- 영수증은 금액·개인정보 마스킹 후에만 공개
  is_public   boolean not null default false
);

-- 구매 후기
create table reviews (
  id          uuid primary key default gen_random_uuid(),
  order_item_id uuid not null references order_items(id) on delete cascade,
  customer_id uuid references customers(id) on delete set null,
  rating      smallint not null check (rating between 1 and 5),
  body        text not null,
  photos      jsonb not null default '[]'::jsonb,
  status      text not null default 'pending',  -- 'pending' | 'published' | 'hidden'
  created_at  timestamptz not null default now()
);
```
`order_item_id` 참조는 **구매 확인된 후기만** 존재하도록 강제한다(§5 원칙).

## 4. 금지 목록 (이 페이지 한정)

- 이모지, 별 장식, 형광 하이라이트, 느낌표 종결
- 텍스트를 구운 배너 이미지 (사진 제외)
- `구매대행`, `대행 수수료`, `관세 폭탄`, `100% 정품 보장!!!`
- 브랜드 로고 이미지 사용 (워드마크 텍스트로 대체)
- 검수 사진 위 워터마크·인증 스탬프·보정
- 후기 없는 상태에서 후기 섹션을 채우는 것
- 재고 미확인 상태에서 구매 CTA를 활성화하는 것
