# 디자인 브리프 — 스토어 홈 + 상품 목록

> `/impeccable shape` 산출물 · 2026-08-26 · 구조: 브랜드 3분할 (Brand Triptych)
> 앵커: [PRODUCT.md](../PRODUCT.md) · [DESIGN.md](../DESIGN.md) · [PDP-TEMPLATE.md](PDP-TEMPLATE.md)
> **이 문서는 코드를 쓰지 않는다.** 구현은 `/impeccable craft` 또는 후속 태스크에서.

---

## 1. 일과 사람

**누가 도착하는가.** 밤에, 모바일로, 이미 검색을 많이 해본 상태로. 비교 대상은 국내 공식몰과
다른 구매대행 스마트스토어다. **의심을 안고 도착한다.**

- **가격을 아는 사람** — 국내 정발가를 알고 왔다. 숫자가 맞는지 검증하러 온다.
- **한국에 없는 것을 찾는 사람** — 원하는 사이즈·컬러가 국내에 없다는 걸 확인하고 왔다.
  가격보다 **존재 여부와 진품성**이 먼저다.

**방문 모드.** Persuade. 이 사람들은 이미 사고 싶다. 설득할 것은 상품이 아니라 **판매자**다.

## 2. 결과와 증거

**첫 화면이 답해야 할 질문:** "여기서 사도 되나?"

| 불안 | 이 화면이 내미는 증거 |
|---|---|
| 정품인가 | 검수 사진, 매입 영수증·인보이스 (사진으로, 배지가 아니라) |
| 관세 얼마 나오나 | 카드마다 예상 세액. USD 150 이하는 면세 표기 |
| 없으면 어쩌나 | 마지막 재고 확인 시각 노출. 미확인이면 구매 CTA를 막는다 |
| 언제 오나 | 주 3회 출고, 영업일 4~10일 |

**이 제품만 할 수 있는 주장.** 알버타는 PST가 없어 GST 5%만 붙는다. 이건 마케팅 문구가 아니라
매입 원가의 사실이고, 가격이 그 결과다.

**성공.** 첫 구매 고객이 "계산이 맞았다"고 확인하고 재구매한다. `관세 폭탄` 문의와
`주문 후 품절` 취소가 발생하지 않는다.

## 3. 선택된 방향 — 브랜드 3분할

**비주얼 권위:** DESIGN.md(29cm 파생). 고정이며 이 브리프는 그것을 바꾸지 않는다.

**구조 명제:** 홈은 세 개의 풀블리드 브랜드 관문이다. 큐레이션이 세 브랜드뿐이라는 사실을
숨기지 않고 구조로 선언한다. 목록은 브랜드 안에서만 존재한다.

**시퀀스:**
```
관문 1  Arc'teryx   풀블리드 사진 + 라틴 워드마크 + 한 문장 + 개수
관문 2  lululemon   동일 구조
관문 3  Coach       동일 구조
─────────────────────────────────────────────
이번 주 입고        가로 스크롤 스트립 (주 3회 리듬 = 재방문 이유)
우리가 하는 일      검수 사진 3장 + 사실 4줄 (정품/출고/상담/교환반품)
관세 안내           15px 산문 두 문단. 경고색 없음
```

**초점 순간:** 관문 사진이 뷰포트를 가득 채우고 그 아래 브랜드 이름이 라틴 디스플레이로 앉는 순간.
텍스트를 사진 위에 겹치지 않는다(DESIGN.md §7).

**구조 명제의 대가:** 3분할만으로는 "새로 들어온 것"을 못 보여준다. 주 3회 출고가 재방문 이유인데
관문은 정적이다. → **'이번 주 입고' 스트립이 이 구멍을 메운다.** 선택 사항이 아니라 구조의 일부다.

**알려진 한계:** 브랜드가 4개를 넘으면 이 구조는 무너진다. 그때는 관문을 목록의 상단 필터로
강등해야 한다. 지금 3개이므로 성립한다.

## 4. 범위와 경계

- **완성도:** 프로덕션. 배포 가능한 수준.
- **폭:** 홈 + 목록 두 화면.
- **인터랙션:** 실제 데이터 연결(`store_variants` 뷰), 필터·정렬·더보기 동작.
- **건드리지 않는 것:** DESIGN.md 토큰, `src/lib/{pricing,customs,shipping}`, 스키마, `/admin`.
- **안티골:** 이모지 · 별점 이미지 · 신뢰 배지 · 그림자 · 8px 이상 반경 · 가격을 카드 상단으로
  · 카운트다운 · `최저가`/`마감 임박` · 관세를 빨간 배너로 · 자동재생 캐러셀
  · 텍스트를 구운 배너 이미지 · 섹션마다 붙는 작은 대문자 이브로우

## 5. 상태와 범위

**데이터 범위:** 상품 50~150개. 브랜드당 30~60개. 옵션(사이즈×색상) 상품당 4~20개.

| 상태 | 처리 |
|---|---|
| 재고 확인 중 (신선도 만료) | 카드 캡션 `재고를 확인하고 있어요`. CTA opacity 0.4. **이미지는 흐리지 않는다** |
| 품절 | 상품명·가격 muted로 강등, `지금은 재입고를 기다리는 중이에요` + 고스트 `재입고 알림 받기` |
| 필터 결과 0건 | 14px muted 한 줄 `검색 결과가 없어요`. 버튼 없음 — 사용자가 필터를 조정한다 |
| 첫 로딩 | 최종 지오메트리의 `#f5f5f5` 평면 블록. **시머 금지** (사진과 경쟁) |
| 더보기 로딩 | 하단 3점 로더. 기존 목록은 계속 보인다 |
| 이미지 로드 실패 | 평면 회색 블록 + alt. 깨진 아이콘을 노출하지 않는다 |
| 상품 0개 (런칭 전) | 관문은 남기고 개수 자리에 `준비 중` |

## 6. 핵심 사용자 플로우 · CTA 경로

**주 화면당 반전 블랙 CTA는 하나뿐이다**(DESIGN.md §4). 홈과 목록에는 구매 CTA가 없다 —
타일과 카드 전체가 클릭 대상이고, 반전 블랙은 상세의 `장바구니 담기`에만 쓴다.
홈·목록의 유일한 반전 블랙은 우하단 고정 문의 컨트롤이다.

### 경로 A — 탐색형 (가격을 아는 사람)
```
홈 도착
 └ 관문 스크롤 (3회)              세 브랜드를 3초 안에 파악
   └ [Arc'teryx 38개 보기] 클릭   ← 타일 전체가 타깃
     └ 목록: 최근 입고순 기본 정렬
       └ 상품 카드 클릭            사진 → 이름 → 가격 → 관세 캡션 순으로 읽힘
         └ 상세: [장바구니 담기]   ← 유일한 반전 블랙
           └ 체크아웃
```
**클릭 수 4회.** 진입에서 결제까지.

### 경로 B — 목적형 (없는 것을 찾는 사람)
```
홈 도착
 └ 헤더 검색 또는 관문 건너뛰고 목록 직행
   └ 목록: [사이즈] 필터로 자기 치수 고정
     └ 상세: 검수 사진 확대해서 택·사이즈 라벨 확인
       └ [장바구니 담기]
```
**이 경로에서 관문은 장애물이다.** 헤더에 브랜드 링크를 항상 노출해 관문을 건너뛸 수 있게 한다.
모바일 관문 높이를 낮추는 이유도 이것이다.

### 경로 C — 재방문 (주 3회 리듬)
```
홈 도착 → '이번 주 입고' 스트립 → 상세 → 구매
```
**클릭 수 2회.** 재방문자를 관문에 다시 가두지 않는다.

### 이탈 지점과 방어
| 이탈 지점 | 방어 |
|---|---|
| 관문 3개를 지나야 목록이 나온다 | 헤더 브랜드 링크 상시 노출. 모바일 관문 60vh |
| 가격을 보고 관세를 걱정한다 | 카드에서 이미 예상 세액을 봤으므로 상세에서 놀라지 않는다 |
| 재고를 의심한다 | 마지막 확인 시각이 카드에 있다 |
| 정품을 의심한다 | 홈 하단 검수 사진 → 상세 검수 갤러리 |

## 7. 레이아웃과 반응형

**컨테이너 1280px 중앙 정렬. 지면 마진 데스크톱 48px / 모바일 20px.**

| | Mobile <768 | Tablet 768–1024 | Desktop 1024–1440 | Large >1440 |
|---|---|---|---|---|
| 관문 높이 | 60vh | 70vh | 85vh | 85vh (1280 컨테이너) |
| 목록 그리드 | 2열 | 3열 | 4열 | 4열 |
| 입고 스트립 | 가로 스크롤 | 가로 스크롤 | 4개 노출 | 5개 노출 |
| 필터 | 하단 시트 | 상단 가로 행 | 상단 가로 행 | 상단 가로 행 |
| 내비 | 햄버거 시트 | 축약 행 | 전체 행 | 전체 행 |
| 지면 마진 | 20px | 32px | 48px | 48px |

- 그리드는 `repeat(auto-fit, minmax(280px, 1fr))`이 아니라 **명시적 열 수**를 쓴다.
  상품 카드는 이미지 비율(4:5)이 고정이라 열 수가 흔들리면 리듬이 깨진다.
- 섹션 헤드라인 30px → 모바일 22px, 웨이트 700 유지.
- **관문 사진은 모든 뷰포트에서 종횡비를 유지한다.** 세로 크롭으로 대응하며 늘이지 않는다.
- 탭 타깃 최소 44×44. 카테고리 배지는 시각 크기와 무관하게 52px.

**필터 (목록):**
- 카테고리 · 사이즈 · 가격대 · 정렬(최근 입고순 기본)
- **`관세 없이 받을 수 있는 것`** — USD 150 이하만 보기. 이 사업만 할 수 있는 필터이고
  '가격을 아는 사람'에게 직격이다. 라벨에 `면세`나 `무관세` 같은 단정 표현을 쓰지 않는다(예상치이므로).
- 선택된 필터는 웨이트 700, 비선택은 400. 색으로 구분하지 않는다.
- 더보기: 24개씩 고스트 버튼(`더보기` + 후행 셰브런). 무한 스크롤을 쓰지 않는다 —
  푸터의 통관·사업자 정보에 도달할 수 없게 된다.

## 8. 모션

DESIGN.md §15 토큰만 쓴다. 새 곡선을 만들지 않는다.

- 관문 진입: 이미지 opacity 0 → 1, 12px 상승. `motion-editorial` + `ease-out`. 스태거 없음(관문은 하나씩 온다)
- 목록 카드: 스크롤 진입 시 스태거 80~120ms, `motion-editorial`
- 카드 호버: 이미지만 1.04 스케일, 카드 크롬은 정지. `motion-standard`
- 고스트 CTA 호버: 보더 `#c4c4c4` → `#000000`, `motion-quick`. 채움 변화 없음
- **등장 애니메이션은 이미 보이는 기본 상태를 강화하는 것이다.** 콘텐츠 가시성을 클래스 트리거에
  걸지 않는다 — 헤드리스 렌더러에서 섹션이 빈 채로 나간다.
- `prefers-reduced-motion: reduce`에서 전부 instant로 붕괴 (globals.css에 구현 완료)

## 9. 제약과 빌더가 지어내면 안 되는 것

**바인딩 제약**
- Next.js 16 App Router, Tailwind v4, 서버 컴포넌트 우선. 목록 필터는 URL 검색 파라미터로.
- 가격·재고는 **`store_variants` 뷰에서만** 읽는다. `product_variants` 직접 조회는 원가 노출이다.
- 예상 세액은 `estimateCustoms()`. UI에서 재계산하지 않는다.
- WCAG 2.2 AA. 읽혀야 하는 보조 텍스트는 `#5d5d5d`(6.58:1). `rgba(93,93,93,0.64)`는 2.92:1이라 **문장에 쓰지 않는다** (DESIGN.md §2).
- 한국어 우선. `word-break: keep-all`.

**이미지 — 실사진이 아직 없다**
- Unsplash로 구현하되 **URL을 반드시 검증**하고 쓴다. 추측한 photo ID는 404로 나간다.
- 검색어는 카테고리가 아니라 물리적 대상으로: `"snow-covered alpine ridge at dusk"`(Arc'teryx),
  `"woman stretching in an empty studio, morning light"`(lululemon),
  `"leather bag on a worn wooden counter"`(Coach)
- **관문 3장은 결정적인 사진이어야 한다.** 어중간한 5장보다 확신 있는 3장이 낫다.
- 교체 지점을 코드에 `TODO(image): 실촬영본으로 교체` 주석으로 남긴다.
- 색 블록으로 사진을 대체하지 않는다. 그건 버그다.

**빌더가 지어내면 안 되는 것 (물어볼 것)**
- 검수 사진과 리뷰는 **스키마에 없다**. PDP-TEMPLATE §3에 제안 DDL이 있으나 미적용이다.
  홈의 '우리가 하는 일' 섹션에 쓸 검수 사진은 현재 소스가 없다 → 플레이스홀더 + TODO.
- 상담 채널(네이버 톡톡 / 카카오 / 자사 폼) 미정 → 플로팅 CTA는 `1:1 문의`로 두고 링크는 TODO.
- '이번 주 입고' 데이터 소스: `purchases.purchased_at` 또는 `products.created_at` 중 무엇을
  기준으로 할지 미정. 전자가 사실에 가깝다.
- 브랜드 로고 이미지 사용 금지 결정은 유지(상표 리스크). 워드마크는 텍스트로 조판한다.
