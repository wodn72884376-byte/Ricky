> 셸(헤더·푸터·플로팅 CTA)은 [00-shell.md](00-shell.md).

## 0. 이 화면이 하는 일

첫 화면이 답해야 할 질문은 하나다 — **"여기서 사도 되나?"** 방문 모드는 Persuade이고,
설득 대상은 상품이 아니라 **판매자**다 (BRIEF §1–2).

## 2. 정보 계층

```
1. 사진        관문 3장이 뷰포트를 지배한다 — 브랜드 큐레이션이 첫 주장
2. 이야기      관문 캡션 한 문장 (15/400). 상품 설명이 아니라 매입 태도의 진술
3. 리듬        이번 주 입고 = 재방문 이유. 주 3회 출고가 여기서 보인다
4. 증거        검수 사진 3장 + 사실 4줄. 배지가 아니라 문서
5. 각주        관세 산문. 마지막이고, 색이 없고, 겁주지 않는다
```

**가격은 홈에 두 번만 등장한다** — 입고 스트립 카드에서 12px/700로. 관문에는 가격이 없다.

**반전 블랙 CTA는 화면 전체에 단 하나 — 플로팅 `1:1 문의`.** 홈에는 구매 CTA가 없다 (BRIEF §6).

## 4. 반응형

| | Mobile <768 | Tablet 768–1024 | Desktop 1024–1440 | Large >1440 |
|---|---|---|---|---|
| 관문 높이 | **60vh** | **70vh** | **85vh** | 85vh (1280 컨테이너) |
| 관문 헤드라인 | 22px / 700 | 30px / 700 | 30px / 700 | 30px / 700 |
| 입고 스트립 | 가로 스크롤 | 가로 스크롤 | 4개 노출 | 5개 노출 |
| 검수 사진 | 1열 세로 스택 | 3열 유지 | 3열 | 3열 |
| 지면 마진 | 20px | 32px | 48px | 48px |
| 섹션 간격 | 32px | 48px | 48px | 48px |
| 내비 | 햄버거 시트 | 축약 행 | 전체 행 | 전체 행 |

- **관문 사진은 모든 뷰포트에서 종횡비를 유지한다.** 세로 크롭으로 대응하고 늘이지 않는다 (BRIEF §7).
- 모바일 관문을 60vh로 낮추는 이유: 목적형 방문자(경로 B)에게 관문 3개는 장애물이다 (BRIEF §6).

## 5. 상태 5종 — §14 규칙 적용

### 5-1. Skeleton (첫 페인트 전)
```
┌─────────────────────────────────────────┐
│                                         │
│      #f5f5f5 평면 블록 · 85vh · 0px      │   ← 관문 자리
│                                         │
└─────────────────────────────────────────┘
  ▭▭▭▭▭▭▭  30px 높이 블록
  ▭▭▭▭▭▭▭▭▭▭▭  15px 높이 블록
```
- 최종 레이아웃 지오메트리 그대로. `#f5f5f5`, 0px radius.
- **1.0s 페이드 펄스. 시머 금지** — 사진과 경쟁한다 (§14 Skeleton / §8 Image Behavior).
- 입고 스트립 카드의 **가격 자리에는 스켈레톤을 쓰지 않는다.** 해결 전까지 `--`로 렌더한다 (§14).

### 5-2. Loading (관문 이미지 지연 / 스트립 추가 로드)
- 관문 이미지: `#f5f5f5` 평면 블록 유지, 시머 없음.
- 스트립 추가 로드: 목록 하단(가로 스크롤 끝)에 `#000000` 3점 로더. 오버레이 없음, 기존 카드는 계속 보인다 (§14 Loading 추가 상품).

### 5-3. Empty (런칭 전 · 상품 0개)
- **관문 3개는 그대로 남긴다.** 사진과 헤드라인은 브랜드 선언이지 재고 표시가 아니다.
- 카운트 자리: `38개` → `준비 중` (12px / 400 / `#5d5d5d`) — BRIEF §5.
- 입고 스트립: 섹션 헤드라인 아래 14px / `#5d5d5d` 한 줄 `아직 입고 기록이 없어요`. 버튼 없음.
- 신뢰 블록·관세 안내는 **정상 노출.** 상품이 없어도 판매자 설명은 유효하다.
- 일러스트·마스코트 금지 (§14 Empty).

### 5-4. Error
| 층위 | 처리 |
|---|---|
| 이미지 로드 실패 | 평면 `#f5f5f5` 블록 + `alt` 텍스트 노출. **깨진 아이콘을 노출하지 않는다** (BRIEF §5) |
| 입고 스트립 페치 실패 | 섹션은 남기고 14px muted 한 줄 `입고 기록을 불러오지 못했어요` + 고스트 `다시 시도하기`. 관문은 영향 없음 |
| 화면 차단 (서버 장애) | 흰 화면, 중앙 `#000000` 16px / 700 한 줄, 아래 고스트 CTA `다시 시도하기`. 일러스트 없음 (§14 Error 화면 차단) |
| 토스트 | `#000000` bg / `#ffffff` 14px·400 / 2px radius / 하단 중앙 / 3초 자동 해제 / 아이콘 없음 |

### 5-5. Success (정상 렌더)
- 관문 3장 + 입고 카드 n개 + 검수 사진 3장 + 관세 산문 2문단이 전부 채워진 상태.
- 홈에는 트랜잭션이 없으므로 **성공 확인 UI가 없다.** 초록 체크마크 금지 (§14 Success 인라인).
- 유일한 인라인 성공 피드백: (해당 시) 찜 토글 — `#000000`/`#ffffff` 반전 번쩍.

## 6. 모션 (§15 토큰만)

| 대상 | 토큰 |
|---|---|
| 관문 진입 | opacity 0→1 + 12px 상승 · `motion-editorial` (400ms) · `ease-out` · **스태거 없음** (관문은 하나씩 온다) |
| 입고 카드 진입 | 스태거 80–120ms · `motion-editorial` · `ease-out` |
| 카드/관문 호버 | **이미지만** scale 1.04 · `motion-standard` · `ease-out`. 카드 크롬 정지 |
| 고스트 CTA 호버 | 보더 `#c4c4c4` → `#000000` · `motion-quick`. 채움 변화 없음 |
| reduce-motion | 전부 `motion-instant`로 붕괴, 호버 스케일 비활성 (§15-6, globals.css 구현 완료) |

**IntersectionObserver reveal은 safety net을 반드시 건다.** 콘텐츠 가시성을 클래스 트리거에만 맡기면
헤드리스 렌더러에서 섹션이 빈 채로 나간다 (BRIEF §8). 기본 상태가 이미 보이는 상태여야 하고,
애니메이션은 그것을 강화만 한다.
