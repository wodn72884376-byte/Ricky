## 0. 이 화면이 하는 일

캘거리 매장에서 산 물건 하나를 **판매 가능한 상태로 만든다.**
원가를 넣으면 판매가가 자동 산출되고, 마진이 목표에 못 미치면 그 사실이 보인다.

**여기서만 원가·마진율·환율이 화면에 등장한다.** 스토어로 새어나가면 §12-7 위반이다.

## 2. 정보 계층

```
1. 무엇인가          브랜드 · 상품명 · slug · 원산지
2. 어떻게 보이나      사진 (대표 사진이 스토어 카드의 4:5)
3. 무엇을 파나        옵션 행 (사이즈 × 색상 × 재고)
4. 얼마나 무거운가    치수·무게 → 배송비·대형 화물 판정
5. 얼마에 파나        산출 열 (sticky) — 폼을 채우는 내내 보인다
```

- **산출 열이 sticky인 이유:** 원가·마진·판매가는 입력의 *결과*이며, 운영자는 입력하면서 이 숫자가
  어떻게 움직이는지 봐야 한다. 마지막에 한 번 보여주면 되돌아가 고쳐야 한다.
- `목록통관 기준 초과`가 산출 열 맨 아래인 이유: 이 상품이 고객에게 세액을 발생시킨다는 사실이
  **등록 시점에** 보여야 가격 정책을 조정할 수 있다.
- 숫자 전부 `tabular-nums`, weight 700, 우측 정렬. **count-up 금지.**

## 5. 상태 5종 — §14 규칙 적용

### 5-1. Empty
- **빈 폼이 정상 진입 상태다.** empty 일러스트·안내 모달 없음.
- 산출 열: 원가 입력 전 모든 수치를 `--`로 렌더 (§14 Skeleton 규칙의 확장 — 미해결 숫자는 `--`).
- 사진 슬롯 4개는 처음부터 dashed 보더로 보인다. `+` 하나만 두고 늘리지 않는다 — 4:5 리듬이 미리 보여야 한다.
- 옵션 테이블: 빈 행 1개를 미리 둔다. `옵션 추가`를 눌러야 첫 행이 나오게 하지 않는다.

### 5-2. Skeleton
- **신규 등록 화면에는 스켈레톤이 없다.** 서버에서 즉시 렌더되는 빈 폼이다.
- 예외: 브랜드 select 옵션 로딩 중 — select를 disabled(opacity 0.4)로 두고 placeholder `불러오는 중`.
- 환율(`1 CAD = 1,010원`) 로딩 중 — 해당 줄만 `--`.

### 5-3. Loading
| 경우 | 처리 |
|---|---|
| 사진 업로드 중 | 해당 슬롯 opacity 0.4 + 하단 12/400 muted 퍼센트. 진행 바 없음 |
| 가격 재산출 | 산출 열 수치 opacity 0.4. **이전 값 유지, `0원`으로 깜빡이지 않는다** |
| 세액 계산 | 세액 줄만 `계산 중이에요` 12/400 muted |
| 등록 제출 중 | CTA opacity 0.4, 라벨 유지, 폼 잠금. 스피너 없음. 오버레이 스크림 금지 |

### 5-4. Error
**인라인 필드 에러** — 13px/400 `#ed0038` + 보더 `1px #ed0038` (§14)

| 필드 | 문구 |
|---|---|
| 상품명 | `상품명을 입력해 주세요.` |
| slug | `이미 쓰고 있는 slug예요.` / `소문자·숫자·하이픈만 쓸 수 있어요.` |
| 원산지 | `원산지를 실물 라벨에서 확인해 입력해 주세요.` |
| 매입가 | `매입가를 입력해야 판매가를 산출할 수 있어요.` |
| 재고 | `재고는 0 이상이어야 해요.` |
| SKU | `이미 쓰고 있는 SKU예요.` |
| 사진 없음 | `대표 사진이 필요해요.` |
| 치수 | `치수를 넣어야 배송비를 산출할 수 있어요.` |

**경고 (에러 아님 — 제출을 막지 않는다)** — 12/700 `#e8005d` 한 줄

| 경우 | 문구 |
|---|---|
| 마진 목표 미달 | `마진 18.2% — 목표 22% 미달` |
| 대형 화물 | `최장변 1m 초과 — 대형 화물 수수료 약 30,000원` |
| 목록통관 초과 | `412 USD — 목록통관 기준 초과` |
| CKFTA 체크 + 원산지 불일치 | `원산지가 Canada가 아니면 CKFTA 대상이 아니에요` — **이건 에러로 승격한다.** 잘못 표시하면 통관 리스크 |

| 그 밖 | 처리 |
|---|---|
| 업로드 실패 | 해당 슬롯에 12/400 `#ed0038` `업로드하지 못했어요` + 고스트 `다시 시도` |
| 제출 실패 | CTA 위 15/400 `#ed0038` 한 줄. **입력값 전부 유지** |
| 환율 조회 실패 | 환율 줄 12/400 muted `환율을 불러오지 못했어요. 판매가를 직접 입력해 주세요.` + 판매가 수동 입력 필드 노출 |

- **에러 요약 배너 금지.** 인라인 + 첫 에러 필드로 포커스 이동 (`ease-standard`).
- 색만으로 전달하지 않는다 — 항상 텍스트 동반.
- `aria-invalid` + `aria-describedby`.

### 5-5. Success
- 등록 성공 → `/admin/products/[id]`로 라우트 전환 (`motion-page`) + 상단에 15/400 한 줄 `등록했어요`.
- 임시 저장 성공 → `임시 저장` 버튼 라벨이 `motion-instant`로 `저장됨`으로 바뀌고 3초 뒤 되돌아온다. 토스트 없음.
- 초록 체크마크·컨페티 금지 (§14 Success 인라인).
- **연속 등록 배려:** 성공 화면에 고스트 `같은 브랜드로 하나 더 등록하기` — 브랜드·원산지·마진율만 승계하고 나머지는 비운다.

## 6. 모션
- 옵션 행 추가/삭제: 높이 확장/붕괴 · `motion-standard` · `ease-standard`.
- 산출 수치 갱신: `motion-instant`. **count-up 금지 — 숫자는 즉시 정확히.**
- 사진 슬롯 드래그 재정렬: `motion-quick` · `ease-out`. 스프링·바운스 금지.
- 등장 애니메이션 없음 (운영 화면).
- reduce-motion: 전부 instant.
