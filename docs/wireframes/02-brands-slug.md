## 0. 이 화면이 하는 일

목록은 브랜드 안에서만 존재한다 (BRIEF §3). 이 화면의 일은 **자기 사이즈를 고정하고
관세 조건을 걸러내는 것** — 목적형 방문자(경로 B)의 작업대다.

## 2. 정보 계층

카드 안의 세로 리듬은 **뒤집을 수 없다** (§12-2, §9 Iteration Guide 4):
```
사진  →  상품명(12/400)  →  가격(12/700)  →  관세 각주(12/400 muted)  →  재고 확인 시각(12/400 muted)
```
- 가격은 상품명과 **같은 크기**다. 크게 만들지 않는다.
- 재고 확인 시각을 카드에 노출하는 이유: "재고를 의심한다" 이탈 지점의 방어 (BRIEF §6).
- 세일 필(`-25%`)은 이 화면의 **유일한 채색 순간**이다. `NEW` / `BEST` / `정품보장`에 쓰지 않는다.

**반전 블랙 CTA는 이 화면에 없다.** 카드 전체가 링크 타깃이고, 유일한 반전 블랙은 플로팅 문의다 (BRIEF §6).

## 5. 상태 5종 — §14 규칙 적용

### 5-1. Skeleton
- 카드 4열 그리드의 **최종 지오메트리**에 `#f5f5f5` 평면 블록. 0px radius, 1.0s 페이드 펄스, 시머 금지.
- 상품명·캡션 자리는 `#f5f5f5` 라인 블록. **가격 자리는 `--`로 렌더한다** (§14 Skeleton).
- 필터 행·카테고리 행은 스켈레톤을 두지 않는다 — 서버에서 즉시 렌더된다.

### 5-2. Loading
| 경우 | 처리 |
|---|---|
| 첫 페인트 | 위 스켈레톤 |
| `더보기` 추가 24개 | 목록 하단 `#000000` 3점 로더. **오버레이도 스켈레톤도 없다 — 기존 목록은 계속 보인다** (§14) |
| 필터 변경 (URL 파라미터 전환) | 기존 그리드를 opacity 0.4로 낮추고 3점 로더. 그리드 높이는 유지해 스크롤 점프를 막는다 |

### 5-3. Empty
| 경우 | 처리 |
|---|---|
| **필터 결과 0건** | 14px `#5d5d5d` 한 줄 `검색 결과가 없어요`. **버튼 없음** — 사용자가 직접 필터를 조정한다 (§14 Empty 검색/필터). 필터 행은 그대로 남긴다 |
| **브랜드에 상품 0개 (런칭 전)** | 브랜드 헤드는 남기고 카운트를 `준비 중`으로. 그리드 자리에 14px muted `아직 등록된 상품이 없어요` |
| 일러스트 | **금지** (§14) |

### 5-5. Error
| 층위 | 처리 |
|---|---|
| 목록 페치 실패 | 그리드 자리에 16px/700 `#000000` 한 줄 + 고스트 `다시 시도하기`. 헤더·필터는 유지 |
| 이미지 실패 | 평면 `#f5f5f5` + alt. 깨진 아이콘 금지 |
| 잘못된 slug | `not-found` — 흰 화면, 16px/700 `없는 브랜드예요`, 고스트 `홈으로` |
| 토스트 | `#000000` / `#ffffff` 14/400 / 2px / 하단 중앙 / 3초 |

### 5-6. Success
- 정상 렌더 = 카드 n개 + 활성 필터가 weight 700으로 표시된 상태.
- 필터 적용 성공을 토스트로 알리지 않는다. **URL과 카운트가 곧 확인이다.**
- 찜 토글: `#000000`/`#ffffff` 반전 번쩍 (§14 Success 인라인). 초록 체크마크 금지.

## 6. 모션
- 카드 스크롤 진입: 스태거 80–120ms · `motion-editorial` · `ease-out`.
- 카드 호버: 이미지만 1.04 · `motion-standard`. 카드 크롬 정지.
- 필터 시트 열림: `motion-standard` · `ease-out`. 닫힘 `ease-in`.
- 고스트 `더보기` 호버: 보더 `#c4c4c4` → `#000000` · `motion-quick`.
