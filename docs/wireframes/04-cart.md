# 04 — `/cart` 장바구니

> **합산과세 경고가 여기 뜬다** (IA §1). 단, 경고는 빨간 배너가 아니라 산문이다 (§12-9).
> 셸: [00-shell.md](00-shell.md)

## 0. 이 화면이 하는 일

'가격을 아는 사람'이 **계산을 검증하는 자리**다. 상품가 · 배송비 · 예상 세액이 각각 얼마인지
결제 전에 분해해 보여주지 않는 사이트를 이 사람은 신뢰하지 않는다 (§13).

동시에 **§12-7의 제약이 걸린다** — 상품 금액은 마진 포함 최종 원화가 하나다.
원가·수수료·환율을 분해하지 않는다. 분해하는 것은 상품가 / 배송비 / 예상 세액 **세 줄뿐이다.**

## 2. 정보 계층

```
1. 무엇을 담았나    사진 → 브랜드 → 상품명 → 옵션 → 가격 → 세액 각주 (카드 리듬 그대로)
2. 얼마인가        상품 금액 / 국제 배송비 / 예상 세액 — 세 줄. 그 이상 분해하지 않는다
3. 결제 예정 금액   22px/700. 이 화면에서 가장 큰 숫자 (§14 Success 주문 완료와 같은 위계)
4. 무엇이 확정 아닌가  `예상`, `약` 표기. 통관 시점 확정임을 한 줄로
5. 합산과세         조건 충족 시에만. 경고가 아니라 사실 진술
```

**숫자 정렬:** 요약 열의 모든 금액은 `font-variant-numeric: tabular-nums`, weight 700, 우측 정렬 (§3).
**숫자에 애니메이션을 걸지 않는다.** count-up 금지 — 가격·세액은 즉시 정확히 표시한다.

## 5. 상태 5종 — §14 규칙 적용

### 5-1. Empty
```
┌─────────────────────────────────────────┐
│                                         │
│   장바구니가 비어있어요.       15/400 #000 │
│   ── 20px ──                            │
│   [ 상품 둘러보기 > ]        고스트 h52   │
│                                         │
└─────────────────────────────────────────┘
```
- §14 Empty(찜/장바구니) 그대로: `#000000` 15px weight 400 한 줄 + 고스트 CTA 하나.
- **일러스트·마스코트 금지.** `데이터가 없습니다` 금지 (§10).
- 요약 패널과 합산과세 블록은 렌더하지 않는다.

### 5-2. Skeleton
- 라인 아이템 자리에 최종 지오메트리 `#f5f5f5` 블록 (썸네일 4:5 + 텍스트 라인 3개).
- **금액 자리는 `--`** (§14 Skeleton). 요약 패널 숫자도 `--`.
- 1.0s 페이드 펄스, 시머 금지, 0px radius.
- 장바구니는 클라이언트 저장소이므로 스켈레톤 노출 시간이 짧다 — **200ms 미만이면 스켈레톤을 띄우지 않는다** (플래시 방지).

### 5-3. Loading
| 경우 | 처리 |
|---|---|
| 수량 변경 → 금액 재계산 | 해당 라인 금액과 요약 패널 숫자를 opacity 0.4로. 값은 이전 값 유지, `0원`으로 깜빡이지 않는다 |
| 삭제 처리 중 | 해당 라인 전체 opacity 0.4. 즉시 제거하지 않는다(낙관적 삭제 금지 — 실패 시 되살아나면 혼란) |
| `주문하기` 제출 중 | 버튼 opacity 0.4, 라벨 유지. 스피너 없음 |
| 가격 재검증 | 하단 3점 로더 `#000000`. 기존 목록은 계속 보인다 |

### 5-4. 재고 · 가격 변동 (이 화면 고유)

> **가격은 장바구니에 저장하지 않고 항상 `store_variants`에서 다시 읽는다** (IA §5-6).
> 따라서 진입 시 가격·재고가 바뀌어 있을 수 있다.

| 경우 | 처리 |
|---|---|
| 가격이 올랐다 | 해당 라인 캡션에 12/400 muted `가격이 689,000원에서 712,000원으로 바뀌었어요`. 빨간색 금지. 요약은 새 가격으로 계산 |
| 재고 확인 중 (신선도 만료) | 라인 캡션 12/400 muted `재고를 확인하고 있어요`. **`주문하기` CTA를 disabled(opacity 0.4)** — 확인 안 된 건 결제를 막는다 (PRODUCT.md) |
| 품절 | 상품명·가격 muted로 강등 + `지금은 재입고를 기다리는 중이에요` + 고스트 `삭제하고 계속하기`. 이미지 흐림·취소선·SOLD OUT 금지 |
| 부분 품절 | 품절 라인만 강등. 나머지는 정상. CTA 라벨을 `남은 상품만 주문하기`로 바꾸지 않는다 — 사용자가 직접 삭제한다 |

### 5-5. Error
| 층위 | 처리 |
|---|---|
| 수량 상한 초과 | 스테퍼 아래 13px/400 `#ed0038` 한 줄 `재고가 2개 남았어요` |
| 재계산 실패 | 요약 패널 예상 세액 자리 12/400 muted `예상 세액을 계산하지 못했어요. 통관 시점에 확정돼요.` — 지어내지 않는다 (§12-8) |
| 저장소 손상 / 파싱 실패 | 흰 지면 16px/700 `장바구니를 불러오지 못했어요` + 고스트 `장바구니 비우기`. 조용히 비우지 않는다 |
| 토스트 | `#000000` / `#ffffff` 14/400 / 2px / 하단 중앙 / 3초 / 아이콘 없음 |

### 5-6. Success
- 수량 변경 성공: 숫자가 즉시 갱신된다. **토스트 없음, 초록 체크 없음** (§14 Success 인라인).
- 삭제 성공: 라인이 `motion-standard` · `ease-in`으로 사라지고 요약이 갱신. Undo 스낵바 없음 — 다시 담으면 된다.
- `주문하기` 성공: `/checkout`으로 라우트 전환 `motion-page` (350ms).

## 6. 모션
- 라인 제거: opacity 1→0 + 높이 붕괴 · `motion-standard` · `ease-in`.
- 스테퍼 숫자 변경: `motion-instant`. **count-up 금지.**
- 고스트 호버: 보더 `#c4c4c4` → `#000000` · `motion-quick`.
- reduce-motion: 전부 instant.
