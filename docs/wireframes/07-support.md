# 07 — `/support` 고객센터

> 자사몰만 운영하므로 문의를 전부 자체로 가져야 한다 (IA §1). 셸: [00-shell.md](00-shell.md)

## 0. 이 화면이 하는 일

운영 시간을 정직하게 알리고(**평일 10–15시**, 1인 운영), FAQ로 대부분을 흡수하고,
남은 것을 1:1 문의로 받는다. 비회원도 접수번호로 다시 볼 수 있어야 한다.

## 2. 정보 계층

```
1. 언제 답이 오는가   운영 시간을 맨 위에. 1인 운영이라는 사실을 숨기지 않는다
2. 스스로 풀 수 있는가 FAQ — 카테고리 → 아코디언
3. 그래도 남으면      1:1 문의 폼
4. 옆길               가이드 4장 · 주문 조회 (사이드)
```

- FAQ 답변은 **가이드 페이지로 링크한다.** 답을 두 곳에 복제하지 않는다.
- 운영 시간을 `24시간 상담` 같은 표현으로 미화하지 않는다 (§12-8 — 모르는 것/못하는 것은 그대로 쓴다).

## 4. 반응형

| | Mobile <768 | Tablet 768–1024 | Desktop 1024+ |
|---|---|---|---|
| 레이아웃 | 1열 — 운영시간 → FAQ → 폼 → **사이드 링크를 맨 아래로** | 1열 | 2열 8:4, 사이드 sticky |
| FAQ 카테고리 | 가로 스크롤 | 가로 스크롤 | 전체 노출 |
| 제목 | 22px / 700 | 30px / 700 | 30px / 700 |
| 폼 필드 | h52 유지, 폭 100% | 동일 | 동일 |
| 제출 CTA | 인라인 폭 100% | 인라인 | 인라인 |
| 지면 마진 | 20px | 32px | 48px |

- 모바일에서 하단 고정 바를 두지 않는다 — 폼 제출은 폼 끝에 있는 게 자연스럽다.
- 플로팅 `1:1 문의`는 이 화면에서도 유지하되, 탭 시 폼으로 스크롤(`ease-standard`) + 첫 필드 포커스.

## 5. 상태 5종 — §14 규칙 적용

### 5-1. Empty
| 경우 | 처리 |
|---|---|
| FAQ 카테고리에 항목 0건 | 14px `#5d5d5d` 한 줄 `아직 등록된 질문이 없어요`. 버튼 없음 |
| FAQ 전체가 비어 있음 | FAQ 섹션 자체를 렌더하지 않는다. 폼을 위로 올린다 |
| 폼 초기 상태 | 빈 필드가 정상. empty UI 없음 |

### 5-2. Skeleton
- FAQ 아코디언 행 자리에 `#f5f5f5` 라인 블록 5개 (h52, 0px radius, 1.0s 페이드 펄스, 시머 금지).
- **운영 시간·폼에는 스켈레톤을 쓰지 않는다** — 정적 콘텐츠다.

### 5-3. Loading
| 경우 | 처리 |
|---|---|
| FAQ 카테고리 전환 | 아코디언 영역 opacity 0.4 유지 + 3점 로더 `#000000`. 높이 유지로 스크롤 점프 방지 |
| 문의 제출 중 | CTA opacity 0.4, 라벨 유지, 필드 잠금. 스피너 없음 |

### 5-4. Error
| 경우 | 처리 |
|---|---|
| 이메일 형식 | 13px/400 `#ed0038` `이메일 주소를 다시 확인해 주세요.` + 보더 `1px #ed0038` |
| 제목/내용 미입력 | `제목을 입력해 주세요.` / `문의 내용을 입력해 주세요.` |
| 주문번호 형식 오류 | `주문번호 형식이 달라요.` — 존재 여부는 검증하지 않는다 (열거 방지, 06 §5-4와 같은 정책) |
| 제출 실패 | CTA 위 15/400 `#ed0038` 한 줄. **입력값은 유지한다.** 토스트가 아니라 인라인 |
| FAQ 페치 실패 | FAQ 섹션에 14px muted `질문 목록을 불러오지 못했어요` + 고스트 `다시 시도하기`. 폼은 영향 없음 |
| 화면 차단 | 흰 화면, 16px/700 한 줄, 고스트 `다시 시도하기` |

### 5-5. Success
```
┌───────────────────────────────────────────────┐
│  문의가 접수됐어요.              15 / 400      │
│  ── 12px ──                                   │
│  INQ-260826-4B7M      22px / 700  ← 접수번호   │
│  ── 12px ──                                   │
│  평일 10시~15시에 순서대로 답해요.  15 / 400    │
│  답변은 입력하신 이메일로도 보내요.             │
│  ── 20px ──                                   │
│  [ 문의 내역 보기 > ]            고스트 h52    │
└───────────────────────────────────────────────┘
```
- 폼을 **접수 확인 블록으로 교체**한다 (§14 Success 주문 완료와 같은 규격).
- 초록 체크마크·컨페티 금지. 토스트로 대체하지 않는다 — 접수번호는 기억해야 하는 정보다.
- `[ 문의 내역 보기 ]` → `/support/inquiry/[id]`.

## 6. 모션
- 아코디언 펼침/접힘: `ease-standard`.
- 카테고리 전환: 콘텐츠 크로스페이드 `motion-standard`.
- 폼 → 접수 확인 전환: 크로스페이드 `motion-editorial`.
- 플로팅 CTA → 폼 스크롤: `ease-standard`.
- reduce-motion: 전부 instant, 스크롤은 `behavior: auto`.
