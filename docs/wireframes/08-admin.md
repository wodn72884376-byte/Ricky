# 08 — `/admin` 운영 대시보드

> register = **product** (PRODUCT.md). 문장이 더 짧고 건조하다. 시각 토큰은 스토어와 동일.
> **사이드바 없음** — 상단 유틸리티 행 하나 (IA §2, DESIGN.md §5). 셸: [00-shell.md §5](00-shell.md)

## 0. 이 화면이 하는 일

1인 운영자가 아침에 열고 **오늘 무엇을 해야 하는지 30초 안에 아는** 화면이다.
액션 큐 → 오늘의 주문 → 마진 요약 (IA §1).

## 0.1 색 제약 (중요)

DESIGN.md 상단에 `omd:unresolved` — **admin semantic color palette가 없다.**
success-green · warning-yellow · info-blue는 **존재하지 않는다.**
경보는 다음 네 가지 기존 수단으로만 구분한다 (§2, §14):

| 수단 | 용도 |
|---|---|
| 반전 블랙 칩 (`#000000` bg / `#ffffff` / 2px / 12px·700) | 승인 대기 건수 — 주의를 끌어야 하는 것 |
| `#e8005d` weight 700 텍스트 | 수집 실패, 마진 미달 — **텍스트만.** 행 전체를 칠하지 않는다 |
| `#5d5d5d` | 보조 수치, 마지막 성공 시각 — 운영자가 읽어야 하는 값이므로 Muted Text |
| opacity 0.4 | 비활성 · 처리 중 |

배경 틴트 금지. 아이콘 금지. **그림자 금지 — 관리자도 마찬가지다** (§6).

## 2. 정보 계층

```
1. 지금 처리할 것   액션 큐. 건수가 0이면 이 블록은 사라진다
2. 오늘 들어온 것   주문 테이블. 경과 시간이 마지막 열 — 방치된 건이 눈에 띈다
3. 이번 주 숫자     매출 · 마진 · 재고. 요약이지 분석이 아니다
```

- **액션 큐가 맨 위인 이유:** 1인 운영에서 병목은 정보가 아니라 처리 순서다.
- 마진율은 여기서만 보인다. **스토어 어디에도 노출되지 않는다** (§12-7, PROJECT §3.1).
- 숫자 열 전부 `font-variant-numeric: tabular-nums`, weight 700, 우측 정렬 (§3).
- **숫자에 count-up 애니메이션을 걸지 않는다.**

## 4. 반응형

| | Mobile <768 | Tablet 768–1024 | Desktop 1024+ |
|---|---|---|---|
| 상단 내비 | 가로 스크롤 행 (햄버거 아님 — 항목이 8개뿐) | 가로 스크롤 | 전체 노출 |
| 액션 큐 | 1열 유지 | 1열 | 1열 |
| 주문 테이블 | **가로 스크롤 컨테이너로 감싼다. 열을 숨기지 않는다** (§8) | 가로 스크롤 | 전체 노출 |
| 메트릭 카드 | 1열 스택 | 2열 + 1 | 3열 |
| 제목 | 22px / 700 | 30px / 700 | 30px / 700 |
| 지면 마진 | 20px | 32px | 48px |

> **§8 명시 규칙: 대시보드 테이블은 모바일에서 열을 숨기지 않는다 — 운영자는 전체 숫자를 봐야 한다.**
> 반응형 카드 변환(테이블 → 카드 리스트)도 하지 않는다. 열 정렬이 곧 비교 가능성이다.

## 5. 상태 5종 — §14 규칙 적용

### 5-1. Empty
| 경우 | 처리 |
|---|---|
| 액션 큐 0건 | **블록 자체를 렌더하지 않는다.** `처리할 게 없어요` 같은 축하 문구도 쓰지 않는다 — 운영자용은 건조하게 |
| 오늘의 주문 0건 | 테이블 자리에 15/400 `오늘 들어온 주문이 없어요`. 버튼 없음 |
| 매출/마진 0 | 숫자 자리에 `0원`. `--`가 아니다 — 0은 확정된 값이다 |
| 재고 경보 0건 | 카드는 남기고 숫자 `0건`, 부연 생략, 고스트 CTA 유지 |

### 5-2. Skeleton
- 각 블록의 최종 지오메트리에 `#f5f5f5` 평면 블록. 0px radius, 1.0s 페이드 펄스, 시머 금지.
- **모든 숫자 자리는 `--`로 렌더** (§14 Skeleton — 가격에 스켈레톤을 쓰지 않는 규칙을 운영 수치에도 적용).
- 테이블: 헤더는 즉시 렌더, 행만 스켈레톤 3줄.

### 5-3. Loading
| 경우 | 처리 |
|---|---|
| 폴링 갱신 | **스켈레톤으로 되돌리지 않는다.** 기존 값 유지 + 블록 우상단 12/400 muted `갱신 중` |
| 액션 처리(승인/발주) | 해당 행 opacity 0.4, 라벨 유지. 즉시 제거하지 않는다 |
| 리포트 페치 | 메트릭 숫자만 opacity 0.4 |

### 5-4. 경보 상태 (§14 대시보드 3종)

```
승인 대기            ┌──┐ 3   반전 블랙 칩. 색이 아니라 반전으로 주의를 끈다
                     └──┘

수집 실패            아크테릭스 3회 연속 실패        12/700 #e8005d
                     마지막 성공 6시간 전            12/400 muted
                     ← 배경 틴트 없음, 아이콘 없음

마진 미달            이번 주 마진   812,000원        30/700 #000000
                     19.7%                          12/700 #e8005d
                     ← 해당 수치만 착색. 행 전체를 칠하지 않는다
```

- 경보에 소리·브라우저 알림·배지 카운트를 붙이지 않는다.
- `⚠` `!` 아이콘 금지. `긴급` `즉시` 같은 부사 금지 — 건수와 사실만 (§10 대시보드 경보).

### 5-5. Error
| 경우 | 처리 |
|---|---|
| 블록 단위 페치 실패 | 해당 블록만 15/400 `불러오지 못했어요` + 고스트 `다시 시도하기`. **다른 블록은 계속 보인다** |
| 액션 처리 실패 | 토스트 `#000000`/`#ffffff` 14/400/2px/하단 중앙/3초. 행은 원상 복구 |
| 권한 없음 | 흰 화면 16px/700 `접근 권한이 없어요` + 고스트 `로그인` |
| 전체 장애 | 화면 차단 — 흰 화면, 16px/700, 고스트 `다시 시도하기`. 일러스트 없음 |

### 5-6. Success
- 액션 처리 성공: 해당 행이 `motion-standard` · `ease-in`으로 사라지고 칩 숫자가 감소.
- **토스트를 띄우지 않는다.** 큐에서 사라진 것이 곧 확인이다.
- 초록 체크마크 금지 (§14 Success 인라인 — 반전 번쩍만).

## 6. 모션
- 행 제거: opacity 1→0 + 높이 붕괴 · `motion-standard` · `ease-in`.
- 칩 숫자 변경: `motion-instant`. **count-up 금지.**
- 블록 진입: **등장 애니메이션을 쓰지 않는다.** 운영 화면은 즉시 읽혀야 한다 (편집 리듬은 스토어의 것).
- reduce-motion: 전부 instant.
