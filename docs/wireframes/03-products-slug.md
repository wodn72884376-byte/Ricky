# 03 — `/products/[slug]` 상품 상세 (PDP)

> 콘텐츠 구조는 **이미 잠겼다**: [docs/PDP-TEMPLATE.md](../../../../docs/PDP-TEMPLATE.md) §2.
> 이 문서는 그 구조에 레이아웃·상태·반응형을 입힌다. 섹션 순서를 바꾸지 않는다.
> 셸: [00-shell.md](00-shell.md)

## 0. 이 화면이 하는 일

세 가지 불안을 순서대로 해소한다 (PRODUCT.md): **정품인가 → 관세 얼마인가 → 없으면 어쩌나.**
승계한 신뢰 구축 순서: 상품 → 정품 약속 → 취급 브랜드 → 차별점 → 후기 → 구매 전 고지.

## 2. 정보 계층

```
1. 사진        상품 사진이 헤드라인 (§12-1)
2. 정체        브랜드 24/700 → 상품명 22/700
3. 가격        22/700 — 상세에서만 카드 규격(12px)을 넘긴다
4. 각주        예상 세액 12/400 muted. 경고 아님
5. 선택        사이즈 그리드
6. 확신        재고 확인 시각
7. 행동        장바구니 담기 — 이 화면의 유일한 반전 블랙
8. 이후        정품 약속 → 브랜드 → 검수 → 후기 → 고지 (긴 편집. 게이팅하지 않는다)
```

**§12-10 "고객은 읽는 사람이다."** 이 페이지는 길다. 브랜드 스토리와 검수 기록을 `더보기`로 가두지 않는다.

## 5. 상태 5종 — §14 규칙 적용

### 5-1. Skeleton
- 히어로 사진 자리: 4:5 `#f5f5f5` 평면 블록, 0px, 1.0s 페이드 펄스, **시머 금지**.
- 상품명·브랜드: `#f5f5f5` 라인 블록.
- **가격 자리: `--`로 렌더.** 스켈레톤을 쓰지 않는다 (§14).
- 사이즈 그리드: 셀 개수를 모르므로 렌더하지 않는다 — 빈 공간을 남긴다.

### 5-2. Loading
| 경우 | 처리 |
|---|---|
| 첫 페인트 | 위 스켈레톤 |
| 사이즈 선택 → 세액 재계산 | 세액 캡션 자리 `계산 중이에요` 12/400 muted. 숫자를 `0원`으로 깜빡이지 않는다 |
| `장바구니 담기` 제출 중 | 버튼 opacity 0.4, 라벨 유지. 스피너 아이콘 없음 |
| 검수 사진 확대 | `motion-editorial` 크로스페이드. **줌 바운스·스프링 금지 — 이 이미지는 증거 문서다** (§15-5) |

### 5-3. Empty
| 경우 | 처리 |
|---|---|
| **후기 0건** | **§5 섹션을 통째로 비운다.** 제목도 내리고, `아직 후기가 없어요`도 쓰지 않는다 (PDP-TEMPLATE §5) |
| 검수 사진 0장 | §4는 남기되 사진 자리에 `TODO(asset)` 플레이스홀더 — 스키마는 있고 실제 사진이 없다. 사실 3행은 유지 |
| 취급 브랜드 대표 상품 없음 | 워드마크 텍스트만 남기고 사진 그리드 생략 |

### 5-4. 재고 · 품절

```
재고 확인 중 (신선도 만료)                    품절 (out_of_stock)
──────────────────────────                  ──────────────────────
사진 · 상품명 · 가격  → 정상 렌더               상품명·가격을 muted로 강등
                                            (이미지는 흐리지 않는다)
재고를 확인하고 있어요   12/400 muted          지금은 재입고를 기다리는 중이에요
                                            12/400 muted
┌───────────────────┐                       ┌───────────────────┐
│   장바구니 담기    │ opacity 0.4           │  재입고 알림 받기  │ 고스트 h52
└───────────────────┘ disabled              └───────────────────┘
보더 색은 바꾸지 않는다 (§14 Disabled)          대각선 취소선 · SOLD OUT 오버레이 금지
```
- **재고 미확인 상태에서 구매 CTA를 활성화하지 않는다** (§7 Don't, PDP §4 금지 목록).
- 품절 사이즈만 있는 경우: 해당 사이즈 셀만 opacity 0.4, 나머지는 정상.

### 5-5. 관세 예상 상태

| 경우 | 카피 · 토큰 |
|---|---|
| 면세 (USD 150 이하) | `관세·부가세 면제 예상` — 12/400 muted. 강조하지 않는다 |
| 과세 | `관세·부가세 약 89,000원 예상 (통관 시 수취인 납부)` — 12/400 muted |
| CKFTA 적용 | `원산지가 캐나다라 관세는 0%예요. 부가세 10%는 부과돼요.` — **"완전 면세"로 안내하지 않는다** (PROJECT §3.3) |
| 계산 불가 | `예상 세액을 계산하지 못했어요. 통관 시점에 확정돼요.` — 지어내지 않는다 (§12-8) |

**빨간색·경고 아이콘·틴트 배경 금지** (§12-9). 이 정보는 12px/400 muted grey가 기본 위계다.

### 5-6. Error
| 층위 | 처리 |
|---|---|
| 사이즈 미선택 후 담기 | 사이즈 그리드 아래 13px/400 `#ed0038` 한 줄 `사이즈를 골라 주세요`. 그리드에 `1px #ed0038` 보더 |
| 장바구니 담기 실패 | 토스트 — `#000000` bg / `#ffffff` 14/400 / 2px / 하단 중앙 / 3초 / 아이콘 없음 |
| 없는 slug | `not-found` — 16px/700 `없는 상품이에요` + 고스트 `홈으로` |
| 페치 실패 | 화면 차단 — 흰 화면, 16px/700 한 줄, 고스트 `다시 시도하기`. 일러스트 없음 |

### 5-7. Success
- 담기 성공: 헤더 장바구니 카운트가 `(0)` → `(1)`로. **토스트를 띄우지 않는다** — 카운트가 곧 확인이다.
- 찜 토글: 반전 번쩍 (§14 Success 인라인). 초록 체크마크 금지.
- 모달 인터셉트("장바구니로 이동하시겠어요?") 금지 — 흐름을 막는다.

## 6. 모션
