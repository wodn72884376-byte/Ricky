## 0. 기록된 해석 결정 (문서 간 충돌 해소)

| 충돌 | 판정 | 근거 |
|---|---|---|
| DESIGN.md §4는 "주 카테고리 행"에 라틴 라벨 16–30px를 두라 하고, IA.md §2는 브랜드 3개를 헤더 좌측 16px/200–800에 두라 한다 | **IA.md를 따른다.** 브랜드 링크는 헤더 1행 좌측 존에 16px. 24–30px 라틴 디스플레이 라벨은 (a) 홈 관문 타일 헤드라인, (b) `/brands/[slug]`의 카테고리 행에서만 쓴다 | IA.md가 네비게이션 전담 문서이며 우선순위 계약상 BRIEF·IA가 하네스 일반 규칙보다 위 |
| DESIGN.md §5 "모바일 지면 마진 16–20px" vs BRIEF §7 "모바일 20px" | **20px 고정** | BRIEF가 더 구체적이고 잠긴 결정 |
| DESIGN.md §8 "데스크톱 편집 2–3열" vs §5 "스토리 1–2열" | **기본 2열.** 3열은 밀도 높은 큐레이션 스트립에 한해 허용 | 두 진술의 교집합 |

## 1. 글로벌 헤더 (스토어 전역)

```
 ← gutter →                        1280px container                        ← gutter →
┌───────────────────────────────────────────────────────────────────────────────────┐
│  z-sticky · bg #ffffff · 보더 없음 · 그림자 없음 · py 20px                          │
│                                                                                   │
│  Arc'teryx  lululemon  Coach  이번 주 입고        RICKY        검색 주문조회 장바구니(0) 로그인 │
│  └────────── 좌 존 ──────────┘              └ 중앙 ┘        └────────── 우 존 ──────────┘  │
└───────────────────────────────────────────────────────────────────────────────────┘
```

| 요소 | 토큰 |
|---|---|
| 배경 | `#ffffff`. 히어로(관문) 위에서는 투명 — DESIGN.md §4 |
| 하단 보더 | **없음.** 분리는 여백이 만든다 (§5 Whitespace) |
| 좌 존 링크 (브랜드 3 + 이번 주 입고) | 16px / weight **200** 비활성 · weight **800** 활성 / `#000000` |
| 중앙 워드마크 | `RICKY` 텍스트 조판. weight 700. 이미지 로고 금지 (BRIEF §9 상표 리스크) |
| 우 존 유틸리티 | 16px / weight 200 / `#000000` |
| 장바구니 카운트 `(0)` | 12px / weight 400 / `#5d5d5d` — 개수를 못 읽으면 상태를 모르므로 Muted Text |
| 링크 탭 타깃 | 높이 52px (시각 높이와 무관) |
| 스티키 동작 | 1행은 유지. **보조 행(카테고리 행)만 스크롤 시 내려놓는다** — 보조 행이 없는 페이지에서는 아무것도 사라지지 않는다 |
| 호버 | 보더 색 변화 없음. weight 200 → 400 전환만, `motion-quick` |

### 모바일 (<768px)

```
┌─────────────────────────────────────────┐
│  ☰            RICKY            검색  장바구니(0) │
└─────────────────────────────────────────┘
```
- `☰` 탭 → **전체화면 시트** (z-sheet). 슬라이드 아님, `motion-standard` + `ease-out` 페이드+8px 상승.
- 시트 내 위계는 데스크톱과 동일:
```
┌─────────────────────────────────────────┐
│  ✕                                       │
│                                          │
│  Arc'teryx            24px / 700         │
│  lululemon            24px / 700         │
│  Coach                24px / 700         │
│  이번 주 입고          24px / 700         │
│  ────────── 여백 32px ──────────         │
│  검색                  16px / 200         │
│  주문조회              16px / 200         │
│  장바구니 (0)          16px / 200         │
│  로그인                16px / 200         │
└─────────────────────────────────────────┘
```
- 시트가 열린 동안 플로팅 문의 CTA는 **가려진다** (z-floating < z-sheet).

## 2. 글로벌 푸터 (4열)

```
┌───────────────────────────────────────────────────────────────────────┐
│ pt 20px · pb 48px · px = gutter · 배경 틴트 없음 · 상단 보더 없음        │
│                                                                       │
│ SHOP            GUIDE            HELP              ABOUT              │  13/700 대문자 라틴
│ Arc'teryx       관세 안내        고객센터          RICKY 소개          │  13-14/400
│ lululemon       사이즈 가이드    자주 묻는 질문    이용약관            │
│ Coach           검수와 정품      1:1 문의          개인정보처리방침    │
│ 이번 주 입고                     주문 조회         교환·반품          │
│                                                   배송 안내          │
│                                                                       │
│ ── 여백 32px ──                                                       │
│ [FILL IN: 캐나다 상호 · 알버타 사업자 등록번호 · 소재지 · 대표자 · 연락처]  │  13/400 muted
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```
- **통신판매업 신고번호 항목을 만들지 않는다** (IA §5-7). 빈 칸도, `준비 중`도 두지 않는다.
- 법적 고지 문구에 한해 `~합니다` 종결 허용 (§10).
- 모바일: 4열 → 2열 → (<480px는 여전히 2열, 1열로 접지 않는다 — 스크롤 길이가 과해진다).

## 3. 플로팅 문의 CTA

```
                                            ┌──────────┐
                                            │ 1:1 문의 │   inset 24px, 우하단 fixed
                                            └──────────┘   z-floating
```
| 속성 | 값 |
|---|---|
| 배경 / 텍스트 | `#000000` / `#ffffff` |
| Radius | 2px |
| 시각 높이 | 31px |
| 폰트 | 15px / weight 400 |
| 패딩 | 4px 8px 4px 14px (§4) |
| **탭 타깃** | **44×44 미만이 되면 안 된다.** 시각 높이 31px이므로 투명 히트영역을 상하 7px씩 확장해 44px를 확보한다 (PRODUCT.md 접근성) |
| 호버 | 배경 4% 밝아짐, `motion-quick`. 변형·그림자 없음 |
| 링크 | `TODO(channel): 상담 채널 미정 — 네이버 톡톡 / 카카오채널 / 자사 폼` (BRIEF §9) |

- 모든 뷰포트에서 유지되는 유일한 컨트롤 (§8).
- **예외 — 모바일 하단 고정 구매 바가 있는 화면(`/products/[slug]`, `/cart`)에서는 구매 바 위로 24px 띄운다.** 겹치면 44px 타깃이 무너진다.

## 5. 관리자 셸

```
┌───────────────────────────────────────────────────────────────────────┐
│  RICKY 운영   상품  재고  주문  매입  모니터링  리포트  설정   운영자 이메일 │
└───────────────────────────────────────────────────────────────────────┘
```
- **사이드바를 두지 않는다** (IA §2, DESIGN.md §5). 스토어와 같은 지면감.
- 같은 1280px 컨테이너, 같은 4px 스페이싱, 같은 `#ffffff` 지면.
- 활성 항목 weight 800, 비활성 weight 200. 밑줄·배경 칩 없음.
- 관리자에는 플로팅 문의 CTA가 없다.
- 관리자 register는 `product` (PRODUCT.md) — 문장이 더 짧고 건조하다. 시각 토큰은 동일.
